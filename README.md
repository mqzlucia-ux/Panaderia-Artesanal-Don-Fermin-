# 🥐 Panadería Artesanal "Don Fermin"
Sitio web creado con **HTML, CSS y JavaScript** para la **Panadería Artesanal Don Fermín**, un emprendimiento familiar dedicado a la elaboración de panificados con masa madre y recetas tradicionales.
El diseño combina estética artesanal, interactividad y efectos visuales modernos.
## 🌐 Vista previa
> 💡 Abrí `index.html` en tu navegador para visualizar el sitio.
## ✨ Características principales
- 🎨 Diseño cálido y artesanal con tipografía moderna.  
- 📸 Galería de productos con botones para ver precios.  
- ⚡ Animaciones suaves (fade-in) al hacer scroll.  
- 💬 Mensajes animados con precios de productos.  
- 📱 Diseño adaptable (responsive).
